# Lab 5 — Spatial Filtering

This notebook demonstrates image smoothing, sharpening, and noise reduction using spatial filters.

- Box and Gaussian filters with different kernel sizes.
- Unsharp masking and Laplacian sharpening.
- Median filtering for salt-and-pepper noise.
- Bilateral filtering for smoothing while preserving edges.

**Libraries:** NumPy, OpenCV, Matplotlib, and scikit-image.

**Run:** Open the notebook in Jupyter and run all cells to view the results.
