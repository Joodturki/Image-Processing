# Lab 6 — Frequency Domain Filtering

This notebook demonstrates image filtering in the frequency domain using the Fast Fourier Transform (FFT).

- Laplacian filtering for edge detection.
- Sobel filtering using padded kernels and FFT multiplication.
- Horizontal, vertical, and combined edge visualization.
- Filtered frequency spectrum visualization.

**Libraries:** NumPy, Matplotlib, and scikit-image.

**Run:** Open the notebook in Jupyter and run all cells to view the results.
